# Triage labels

The engineering triage workflow uses the default canonical labels:

| Role | GitHub label |
| --- | --- |
| Needs initial triage | `needs-triage` |
| Needs reporter information | `needs-info` |
| Ready for an implementation agent | `ready-for-agent` |
| Requires human judgment/action | `ready-for-human` |
| Intentionally not planned | `wontfix` |

Keep these strings stable so automated triage and implementation workflows share one vocabulary.
