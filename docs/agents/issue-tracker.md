# Issue tracker

MiniShop uses **GitHub Issues** in `riddler9999/minishop` as the canonical work tracker for engineering skills.

- Create implementation/spec/triage work as GitHub Issues.
- Link pull requests to their originating issue when one exists.
- PRs are not treated as an inbound triage queue by default.
- Do not create a parallel local issue system under `.scratch/` unless this file is explicitly changed.
