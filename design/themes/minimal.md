# Theme: Minimal (Default)

**Status:** matches the storefront tokens already shipping in `src/index.css` — this is not
a new theme to build, it's the existing look, documented so the other two themes have a
baseline to diff against.

## Palette

| Role | Token (existing) | Value |
|---|---|---|
| Background | `--color-cream-50` | `#f6f7fb` |
| Surface / card | `--color-cream-100` | `#eef0f7` |
| Divider | `--color-cream-200` | `#dde1ee` |
| Primary / CTA | `--color-brand-500` | `#fe2c55` |
| Primary hover | `--color-brand-600` | `#e01347` |
| Accent | `--color-gold-500` | `#25f4ee` |
| Text | `--color-ink` | `#1c2033` |
| Text muted | `--color-ink-soft` | `#5b6178` |

## Typography

Display: Space Grotesk. Body: Padauk / Noto Sans Myanmar. Same as global tokens in §2 of
`design/design.md` — this theme doesn't override fonts.

## Tone

Clean, cool-toned, product-photography-forward. Generous white space, pink used sparingly as
a single accent (CTA buttons, price, active nav) rather than as a background color. Default
for any shop category that hasn't picked a theme — must look acceptable for fashion,
beauty, electronics, and general goods alike, since it's the fallback.
